# Telegram Mood Bot

Простой Telegram-бот на Python, который выдает задания в зависимости от настроения пользователя.

## Функционал
- Регистрация имени
- Выбор настроения (1–10)
- Генерация заданий
- Сохранение данных в JSON

## Технологии
- Python
- pyTelegramBotAPI

## Запуск

1. Установить зависимости pip install -r requirements.txt
2. Создать .env файл с токеном
3. Запустить main.py
